# 🧙‍♂️ Desafio de Código: A Jornada do Herói

Repositório com a resolução do desafio de lógica de programação da **DIO (Digital Innovation One)**.

## 📝 Descrição
O herói começa em uma posição inicial na floresta e precisa dar uma quantidade de passos para alcançar a caverna do dragão. O objetivo é calcular sua posição final.

## 📥 Entrada
- Posição inicial (número inteiro)
- Total de passos (número inteiro)

## 📤 Saída
- `Posicao final do heroi: [resultado]`

## 🚀 Como executar
Com o [Node.js](https://nodejs.org/) instalado, execute no terminal:

\`\`\`bash
node index.js
\`\`\`
